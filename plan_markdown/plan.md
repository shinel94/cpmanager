## 개요

음악 작곡을 도와주는 브라우저 기반의 프로그램

### 주요 기능

- 송폼에 맞는 코드 진행 추천
  - 이때 코드 진행은 도수를 기반으로 1도 - 2도 - 4도 - 5도 와 같이 진행을 추천하고 어떤 조성으로 진행할지 선택하고, 해당 조성에 맞는 코드로 자동으로 변환
  - 진행을 추천받은 뒤에 필요한 경우 수정할 수 있고, 이때 그렇게 진행을 수정하는 경우 어떤 기법(모달 인터체인지, 세컨더리 도미넌트 등)을 적용했는지 확인이 가능하면 해당 변경은 어떤 기법을 적용하는 것이다라는 것을 사용자에게 전달, 맞는 조건이 없는 경우에는 생략
- 기본적으로 1마디에 코드 1개를 전재로 하나, 필요한 경우 최소 1박을 기준으로 코드 설정 가능
- 가능한 코드 진행은 미리 데이터베이스에 저장해두어서, 사용자가 프리코러스에서 2도를 입력했을때 추천하는 진행이 검색되도록 기능 제공
- 브라우저를 UI를 제공하여, 작곡할 수 있도록 기능 제공
- 아래 기능은 필수적인 기능은 아니며, 위 기능이 모두 확보된 뒤에 추후 단계에서 진행
  - bpm및 코드 진행을 재생할 수 있어야하며, 박자를 설정하고 해당 박자에 코드의 소리를 midi로 재생하는 기능 제공
