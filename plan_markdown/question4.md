3. 4마디보다 긴 진행의 의미

- 사용자가 작성하는 곡은 여러 개의 4마디 블록이 연결되는 구조이며, 내부에 저장된 진행 데이터에 특정 송폼에 많이 쓰인다는 것도 포함하여, pre chorus 1\~4번째 마디에 진행을 추천하는 형태, 8마디의 prechorus를 1\~4번째 5\~8번째로 나눠서 각각 추천 및 이후 진행 기법역시 4마디 단위로만 추천함

4. 여러 코드가 있는 마디의 분석 범위

- [question3.md](http://question3.md)의 “해당 마디만 제외”는 해당 마디만 분석에서 제외하고 나머지 3마디는 분석한다는 의미로 이해했습니다. -&gt; 정확하며, 만약 2번째 마디에 여러 코드가 있는 경우가 존재한다면 1번째 마디와 진행을 분석할때 다음 진행이 있는경우에는 2번째 마디의 처음 나오는 코드를 기준으로 기법을 분석, 3번째 마디에 만약 기법을 분석하는데 앞의 마디의 코드가 필요하다면 2번째 마디의 마지막 코드를 기준으로 분석하며 중간에 포함된 코드는 활용되지 않고, 2번째 마디는 진행을 별도로 하지 않음.

6. 사용자 추가 진행 검색

- 사용자가 저장한 진행은 일반 추천 목록에는 나오지 않고 별도의 검색 화면에서만 조회하는 것으로 이해했습니다.

- 코드 진행이기 때문에 4마디 기준으로 코드를 추천할때 현재 설절된 코드들을 기준으로 겹치는 경우에만 검색 결과로 포함된 1도 2도 1도 1도 가 내부에 저장되어 있다면 1도 2도 또는 1도 2도 1도가 설정된 경우에는 검색되나 1도 1도 또는 1도 2도 2도 로 검색하면 비슷하더라도 검색되지 않으며 코드 진행만 확인할 수 있도록 설정하고 내가 저장한 코드 진행 목록을 별도로 확인 및 관리할수있는 UI에서 이름으로 검색 또는 코드 진행으로 검색할수있도록 기능 제공
